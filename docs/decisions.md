## 已实施

### D-001：使用 Astro 静态站点架构

项目使用 Astro、Content Collections、Markdown/MDX 和静态路由生成。该架构适合以文章为核心、无需服务端数据库的个人博客。

### D-002：开发环境可见草稿，生产环境隐藏草稿

`getPublishedPosts()` 根据 `import.meta.env.PROD` 过滤 `draft: true` 的内容，便于本地预览未发布文章。

### D-003：全站支持深浅主题

主题偏好保存在 `localStorage`，首次访问时跟随操作系统。颜色由 CSS 变量统一管理。

### D-004：以中文为主语言

页面根语言为 `zh-CN`，日期格式、界面文案、SEO locale 和现有内容均以中文为主。项目当前没有多语言路由。

### D-008：采用文雅、适合屏幕阅读的中英文字体组合

目标气质接近“华文仿宋”的书卷感，但不直接依赖系统中的“华文仿宋”。该字体并非所有 Windows、macOS、Android 和 iOS 设备都稳定提供，直接指定会造成跨平台显示不一致。

全站采用以下字体栈：

```css
Inter, "LXGW WenKai Screen", "STFangsong", "FangSong", serif
```

实施状态：

- 通过 `@fontsource/inter` 在站内加载 Inter 拉丁字符的 400、500、600、700 字重；
- 通过 `lxgw-wenkai-screen-webfont/lxgwwenkaiscreen.css` 在站内加载霞鹜文楷屏幕阅读版 400 字重；
- 霞鹜文楷资源按 Unicode 范围拆分为 WOFF2 子集，浏览器按页面实际出现的字符请求所需文件；
- 两套字体均使用 `font-display: swap`，字体加载期间允许后备字体先显示；
- `STFangsong`、`FangSong` 和通用 `serif` 继续作为加载失败时的后备字体；
- 代码块继续使用独立的等宽字体，不套用正文书写字体。

生产构建会把这些字体复制并哈希化到 `dist/_astro/`，无需访问第三方字体 CDN。当前构建产出 101 个 WOFF2 文件，总体积约 5.2 MB；这是可用字符全集的总量，实际单页由浏览器根据 Unicode 范围按需下载。

霞鹜文楷不是严格的仿宋，但更接近目标中的文雅、舒适和轻微手写感，并针对屏幕阅读优化。参考站 `https://blog.runningotter.com/` 在 2026-09-13 的公开样式中使用 `Inter, LXGW WenKai Screen, PingFang SC, Noto Sans SC, system-ui, sans-serif`。由于 Inter 不包含中文字形，中文会继续回退到霞鹜文楷。参考依据：[Running Otter 样式表](https://blog.runningotter.com/_astro/Base.CXthJy_o.css)、[Inter 官方仓库](https://github.com/rsms/inter)、[霞鹜文楷屏幕阅读版](https://github.com/lxgw/LxgwWenKai-Screen)和 [MDN Web Fonts](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Text_styling/Web_fonts)。

### D-010：使用身份签名与页面索引组成简洁页脚

全站页脚采用左右两栏结构：左侧显示可返回首页的 `@沈高高`，右侧依次提供“首页、归档、关于、RSS”索引，并使用细竖线分隔。页脚索引在鼠标悬停或键盘聚焦时使用红色文字，并显示从中间展开的 2px 红色下划线；下划线只覆盖文字宽度，不包含分隔线留白。页脚与顶部导航使用同一站点宽度，不显示年份、版权符号、GitHub 链接或明显的顶部分隔线；移动端改为上下两行并允许索引换行。`/rss.xml` 端点及其页脚入口均保留，RSS 链接的无障碍名称为“RSS 订阅”。

### D-011：页头采用头像、英文名称和导航的两行品牌结构

页头左侧使用 `pic/jiamo.jpg` 作为头像，桌面端按 88×88px 显示并使用轻微圆角；Astro 在构建时将其优化为 WebP。头像右侧第一行使用 Inter 700 显示 `Shen Gao Gao`，第二行保留“首页、归档、关于”导航。最右侧操作区横向排列 GitHub 按钮和主题切换按钮，GitHub 始终在左、主题切换始终在右且不换行；GitHub 按钮使用内嵌 SVG 图标，在新标签页打开 `https://github.com/DreamCasterZero`。页头与正文统一使用 780px 内容版心，使头像与正文左边缘对齐；头像和名称的桌面端水平间距为 18px。移动端头像缩小到 56×56px、名称缩小到 24px，导航单独占据下一行，操作区保持在右上角。

### D-012：导航当前项使用红色文字标识

顶部导航不再使用蓝色底部横线表示当前页面，改为仅将当前项文字显示为红色，并保留 `aria-current="page"` 供辅助技术识别。鼠标悬停或键盘聚焦任一导航项时，该项文字变红，同时显示一条从中间展开的 2px 红色下划线；交互结束后下划线收起。下划线仅覆盖文字宽度，不包含相邻导航项为虚线分隔符预留的左侧间距。浅色主题使用 `#d52a42`，深色主题使用更明亮的 `#f06478`，导航布局和分隔线保持不变。

### D-013：归档作为唯一文章总览入口

顶部和页脚导航不再显示“文章”，首页“查看全部”和文章页返回入口统一指向 `/archive/`。归档页负责完整文章索引：左侧按最近年份优先分组，使用“完整日期 + 带下划线标题”的安静列表；右侧显示从已发布文章自动汇总的标签索引，并使用浅红描边标签块。窄屏下改为单栏，标签索引位于文章列表之后。文章详情继续使用 `/blog/[...slug]/`，但页头会把“归档”标记为当前栏目；原 `/blog/` 列表页暂时保留以兼容已有地址，但不再提供站内入口。

### D-014：首页最新文章使用紧凑日期列表

首页“最新文章”最多展示最近 6 篇，只保留完整发布日期和文章标题，不显示阅读时间、摘要与标签。分区标题使用 24px / 600，并通过一条浅色横线连接右侧红色“查看全部”入口；文章标题默认显示 1px 细下划线，悬停或键盘聚焦时改为导航红色。桌面端日期与标题分列对齐，移动端改为日期在上、标题在下。该列表由首页独立实现，不改变标签页和旧兼容文章列表使用的 `PostList.astro`。

## 已确认但尚未实施

### D-005：首页以内容模块为主体

首页不再以大型个人介绍为主体，而是展示多个长期内容方向，并在下方展示若干最新文章。

实施状态：原有的英文方向、个人问候和站点描述开场已移除；首页已经加入“版块”区，第一阶段展示数学基础、运动控制、大模型知识和人形机器人四个技术方向，并在下方展示最新文章。版块当前仅用于介绍，尚未设置跳转。

最新文章区已实施紧凑列表：仅显示完整日期和带下划线标题，分区标题与“查看全部”之间使用浅色横线连接；摘要、标签和阅读时间不在首页出现。

### D-006：个人资料集中在“关于”页面

个人信息、自我介绍和博客说明放在主导航的“关于”页面。首页的“个人感”来自内容选择与视觉气质，而不是重复自我介绍。

实施状态：“关于”页面已改为简洁的个人介绍，说明作者在武汉从事机器人运动控制工作、写作动机以及希望用经验记录帮助他人的初衷；旧版英文 `About` 标识和模板分区已经移除。

### D-007：内容同时包含技术与生活

第一阶段技术版块已经确定并展示为数学基础、运动控制、大模型知识和人形机器人。生活候选模块为读书、旅行、美食、时事和个人思考，尚未加入首页，最终分类仍可调整。

### D-009：重新建立字号和行高层级

当前问题不是全站单纯偏大或偏小，而是标题、导航、模块和文章列表之间的比例不协调。计划采用以下目标值：

| 位置 | 当前值 | 目标值 |
| --- | --- | --- |
| 全站基础字号 | 17px | 16px |
| 导航文字 | 约 15px | 16px |
| 网站名称 | 约 18px | 24px |
| 首页大型个人标题 | 约 42–78px | 在模块型新首页中取消 |
| 首页模块标题 | 17px | 22–24px |
| 模块卡片标题 | 尚未设计 | 17–18px |
| 模块说明 | 尚未设计 | 14–15px |
| 首页文章标题 | 约 21–26px | 16–18px |
| 文章正文 | 17px / 1.95 行高 | 17px / 1.85 行高 |
| 文章页标题 | 约 37–62px | 34–44px |

参考站的基础排版为 `16px`、`1.75` 行高和约 `0.33px` 字间距。本站以此为比较基准，但文章正文单独保留 `17px`，兼顾中文长文阅读。

本次排版调整的优先级为：

1. 配合模块型首页取消当前过大的个人标题；
2. 将模块标题提升到 22–24px，建立清晰的首页分区；
3. 将首页文章标题收敛到 16–18px，形成安静、紧凑的“日期 + 标题”列表；
4. 全站界面以 16px 为基准，文章正文独立使用 17px / 1.85 行高。

局部实施状态：“关于”页标题已调整为 36px / 600；介绍正文采用 17px / 400、1.85 行高、24px 段落间距和正文主色。其余页面的字号层级仍待后续统一。
