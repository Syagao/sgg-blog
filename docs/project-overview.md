# 项目概览

## 项目是什么

这是沈高高的中文个人博客，生产域名配置为 `https://shengaogao.com`。项目以静态站点形式发布，内容同时覆盖机器人算法等技术主题与个人生活记录。

当前仓库由 Astro 官方博客项目演化而来，已经具备文章、标签、归档、RSS、站点地图、深浅主题和 MDX 等基础能力。

## 当前内容定位

README 和现有文章体现的主题包括：

- 机器人算法、机器人调度与系统设计；
- 运动控制、轨迹规划和系统辨识；
- 编程学习、工程实践与工作复盘；
- 读书、旅行、美食、时事和个人思考等生活内容。

## 已确认的改版方向

- 博客整体偏个人表达，并以舒适、耐看的阅读体验为目标。
- 个人资料和自我介绍放在导航中的“关于”页面，不以大型个人介绍作为首页主体。
- 首页计划先呈现多个内容模块，再在下方展示若干最新文章。
- 技术模块候选包括数学基础、运动控制、人形机器人和大模型知识。
- 生活模块候选包括读书、旅行、美食、时事和个人思考。
- `https://blog.runningotter.com/` 是信息组织与视觉气质的参考之一，不代表需要逐项复刻。

## 尚未确定

- 首页模块最终数量、命名、分组与排序；
- 模块点击后进入专题页、标签页还是其他聚合页；
- Inter 与霞鹜文楷屏幕阅读版已经作为本地站点资源接入；字号和行高层级仍待落实；
- 颜色、卡片细节与页面宽度等其余视觉系统；
- 首页是否保留任何一句式说明或副标题；
- 部署平台及自动发布流程尚未在仓库资料中记录。

## 当前非目标

仓库中没有评论、账户、数据库、后台编辑器或动态 API。除非后续明确提出，不应把它们视为当前改版的一部分。
