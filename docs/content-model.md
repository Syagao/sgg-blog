# 内容模型

## 内容位置

文章保存在 `src/content/blog/`，文件格式支持 `.md` 和 `.mdx`。文件相对路径形成文章 `id`，站点使用它生成 `/blog/<id>/` 路径。

## Frontmatter schema

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | string | 是 | 文章标题 |
| `description` | string | 是 | 列表摘要和页面元描述 |
| `pubDate` | date | 是 | 发布时间，可由字符串转换 |
| `updatedDate` | date | 否 | 最近更新时间 |
| `heroImage` | image | 否 | 文章主图 |
| `tags` | string[] | 否 | 默认空数组，用于标签页与 RSS 分类 |
| `draft` | boolean | 否 | 默认 `false` |

示例：

```yaml
---
title: "文章标题"
description: "文章摘要"
pubDate: "2026-09-13"
updatedDate: "2026-09-13"
tags: ["机器人", "运动控制"]
draft: false
---
```

## 发布规则

- 文章按 `pubDate` 从新到旧排序。
- 生产构建排除 `draft: true` 的文章。
- 开发环境会包含草稿，列表中显示“草稿”标记。
- 标签直接来自各文章的 `tags`，构建时为每个唯一标签生成聚合页。
- RSS 包含文章标题、描述、发布日期、链接和标签分类。

## 阅读时间

`src/utils/blog.ts` 会先移除代码块、HTML 和常见 Markdown 符号，再按以下速度估算：

- 中文字符：每分钟 400 字；
- 拉丁词语：每分钟 220 词；
- 最少显示 1 分钟。

## MDX 能力

MDX 文章可以导入 Astro 组件和本地图片。现有示例使用 `Callout.astro` 展示说明、提示和警告，并使用 Astro 图片资源。

## 模块与标签的边界

首页计划中的数学基础、运动控制、人形机器人、大模型、读书、旅行等“模块”尚未进入 schema。当前代码只有自由标签，没有独立的栏目、专题、系列或学习路径模型。在产品决定明确前，不应擅自把模块等同于标签。
