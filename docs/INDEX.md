# 项目知识库

本目录记录 `yuxiang-blog` 当前已经验证的项目事实、已经确认的产品方向，以及仍待确认的事项。代码行为与文档不一致时，以代码为准，并在相关改动中同步更新文档。

## 文档导航

- [项目概览](./project-overview.md)：项目目标、受众、当前范围和产品方向。
- [系统架构](./architecture.md)：技术栈、页面、组件、构建和运行时数据流。
- [内容模型](./content-model.md)：文章 frontmatter、发布规则、路由和写作能力。
- [决策记录](./decisions.md)：已经确认的选择与仍处于提案阶段的方向。
- [当前状态](./status.md)：已完成能力、已知问题、验证结果和下一步。

## 维护约定

- 只记录能从代码、仓库资料或用户明确表述中确认的信息。
- 使用“已确认”“提案”“待确认”区分成熟度，不把讨论中的建议写成既定方案。
- 架构、路由或内容 schema 改变时，更新对应专题文档。
- 产品方向或视觉原则确定时，更新 `decisions.md`；近期进展和问题更新到 `status.md`。
- 文档保持轻量，避免复制可直接从代码读到的大段实现。
